# Language-code data attribution

The included `iso6393.js` snapshot comes from [Titus Wormer’s iso-639-3 project](https://github.com/wooorm/iso-639-3). Its MIT copyright and permission notice is included in `wooorm-iso-639-3-MIT.txt`.

The underlying identifiers are ISO 639 language codes. [ISO identifies SIL International as the Language Coding Agency for Set 3](https://www.iso.org/iso-639-language-code). The Library of Congress maintains Set 2 and Set 5. ISO states that its country, currency, and language codes are free to use.

Publisher references:

- [SIL ISO 639-3 code tables and download information](https://iso639-3.sil.org/code_tables/download_tables)
- [Library of Congress ISO 639-2 code list](https://www.loc.gov/standards/iso639-2/php/code_list.php)
- [ISO language-code overview and maintenance agencies](https://www.iso.org/iso-639-language-code)

This notice identifies the data sources. It does not place the underlying ISO standards or SIL publications under the bundle code’s MIT license. Keep these attributions and the original notices when redistributing the bundle.
